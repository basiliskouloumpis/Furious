# 🏎️ Furious — Neon Pursuit

A self-contained, browser-playable, neon-themed 2D highway racing game built with **HTML5 Canvas, CSS, and vanilla JavaScript**. It requires no libraries, build tools, or external image assets.

> This is a newly created game for the repository `basiliskouloumpis/Furious`; it is not a verified copy of any existing project content.

## Features
- Three-lane nighttime highway with animated road markings
- Keyboard and touch steering
- Dodging traffic and increasing difficulty
- Nitro boost with rechargeable energy and collectible energy pickups
- Score, speed, best score (stored locally), restart and pause
- Responsive layout and GitHub Pages compatibility

## Controls
| Action | Keyboard | Touch |
|---|---|---|
| Steer left | `←` or `A` | `◀` |
| Steer right | `→` or `D` | `▶` |
| Nitro | `Space` (hold) | `⚡ NITRO` (hold) |
| Pause/resume | `P` | — |
| Start/restart | `Enter` | Start button |

## Run locally
Open `index.html` in a modern browser. No installation required.

## Publish on GitHub Pages
1. Back up your existing repository files.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root on the publishing branch.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, your publishing branch (often `main`), and `/(root)`.
5. Once deployment succeeds, open `https://basiliskouloumpis.github.io/Furious/`.
